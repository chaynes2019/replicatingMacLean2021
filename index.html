GATA1–PU.1 genetic switch

Eqns 1–3, Rommelfanger & MacLean (2021) · RK4, no solver library
dG/dt = −β₁G + (α₁A + α₂G) / (1 + γ₁A + γ₂G + γ₃GP)
dP/dt = −β₂P + (α₃B + α₄P) / (1 + γ₄B + γ₅P + γ₆GP + γ₇GX)
dX/dt = −β₃X + α₅G / (1 + γ₈G + γ₉C)

Simulation

step = RK4 step size h (time units). speed = RK4 steps per animation frame. Big h with large rates can go unstable — try it.

Cells & signaling

Cells are numbered from 1. a>b = consensus signal from a to b; a-|b = dissensus signal.
Same seed + Reset state replays exactly the same random signals. In network mode A is each cell's resting value A₀; signals multiply it briefly.

Drag any slider while the simulation runs; the next RK4 step uses the new value. Double-click a label to restore its Table S1 value.
